# jsminecraft
A playable 3D block based clone of the famous Minecraft game.
Using three.js for swift and responsive graphics rendering.

100% Javascript - crazy, huh?

## Requirements
- Modern web browser (Chrome, Firefox, Opera, Safari, Edge, etc)

## Features
- Maps:
  - Autogenerated (random each time)
  - Automatic render distance to ensure >=60fps (min distance configurable in source)
- Environment:
  - Night and day
  - Weather (rain, snow, thunderstorms)
- Sound effects:
  - Synthetic sound effects for walking, fight/hit, swimming, weather
- Nature:
  - Various trees (eg. pine, birch)
  - Grass, oats, and seeds (can be planted and will grow)
- Villages:
  - Villages with buildings
  - Villagers exist, but no interaction yet
- Enemies:
  - Creepers
  - Zombies
  - Skeletons
  - Spiders
- Livestock:
  - Chickens (with eggs that may or may not hatch)
  - Horses
  - Sheep
  - Pigs
- Crafting:
  - Basic crafting (from inventory)
  - Workbench can be built for more advanced crafting

## Not yet implemented
- Background music:
  - No ambient music yet, maybe autogenerated later?
- Villager interaction
- Doors, bed, furnace, etc
- More enemies. Not all will be implemented, but should include:
  - Enderman
  - Drowned zombies
  - Zombie villager
- More animals:
  - Cows, foxes, dogs, fish, etc
- Feel free to add the features you miss the most!

## Maybe later
- Multiplayer/game servers
  - Compatibility with original game is not within scope

## Challenging
- Load/save/continue function
  - The maps are huge and contain lots of data, load/save will at best be downloadable binary blobs
