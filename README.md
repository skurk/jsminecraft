# jsminecraft
A playable 3D block based clone of the famous Minecraft game.
Using three.js for swift and responsive graphics rendering.

100% Javascript - crazy, huh?

## Requirements
- Modern web browser (Chrome, Firefox, Opera, Safari, Edge, etc)

## Features
- Autogenerated maps
- Enemies (creepers, zombies, skeletons, and spiders)
- Livestock (chickens, horses, sheep, etc)
- Day and night, sun and clouds
- Weather, rain, thunderstorms
- Basic crafting
- Villages with villagers (although no interaction yet)
- Rudimentary sound effects (weather, walking, swimming, hit/use)
- Automatically reduce render distance if fps<60 (min distance is configurable)

## Missing features
